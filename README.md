# DonorMate

> Telegram Mini App для организации и участия в донорских мероприятиях.
> Проект разработан командой **«Хакатоновые Монстры»** в рамках **Nuclear IT Hack 2025**.

## 🚀 О проекте

**DonorMate** — это Telegram-бот со встроенным WebApp-интерфейсом, который помогает:

* организовывать донорские мероприятия;
* регистрироваться на сдачу крови;
* отслеживать расписание событий;
* взаимодействовать с организаторами;
* получать уведомления и напоминания.

Проект ориентирован на удобное взаимодействие пользователей прямо внутри Telegram без необходимости устанавливать отдельное приложение.

---

## ✨ Возможности

### 👤 Личный кабинет пользователя

* регистрация и авторизация через Telegram;
* хранение пользовательских данных;
* просмотр истории мероприятий.

### 📅 Система мероприятий

* список ближайших и прошедших событий;
* регистрация на мероприятия;
* просмотр информации о мероприятии.

### 📢 Связь с организаторами

* взаимодействие через Telegram-бота;
* уведомления о предстоящих событиях.

### 🛡️ Панель организатора

* создание мероприятий;
* аналитика активности доноров;
* управление участниками.

### 🔐 Система подтверждения организаторов

Для получения прав организатора пользователь:

1. пишет боту;
2. получает временный код;
3. код хранится в Redis 10 минут;
4. после подтверждения открывается доступ к функциям организатора.

### 📲 QR-коды мероприятий

* генерация QR-кодов;
* быстрая регистрация участников;
* удобный check-in на мероприятиях.

## ⚙️ Архитектура

```text
Telegram Bot
    ↓
Telegram WebApp (React)
    ↓
Backend API (Python)
    ↓
PostgreSQL
    ↓
Redis / RabbitMQ
```

* **PostgreSQL** — основная база данных;
* **Redis** — временное хранение кодов подтверждения;
* **RabbitMQ** — отправка уведомлений пользователям.

## 📦 Установка и запуск

### 1. Клонирование репозитория

```bash
git clone https://github.com/tuhlopuz1/DonorMate.git
cd DonorMate
```

### 2. Настройка backend

```bash
cd backend
pip install -r requirements.txt
```

### 3. Настройка frontend

```bash
cd frontend
npm install
```

### 4. Запуск проекта

Backend:

```bash
python main.py
```

Frontend:

```bash
npm run dev
```
